# Правила хранения артефактов Sentinel

## Категории артефактов и сроки хранения

| Артефакт | Retention | Зачем храним |
|----------|-----------|--------------|
| `raw_html` | 30 дней | Отладка парсинга, восстановление логики извлечения |
| `screenshots` | 7 дней | Визуальная проверка, но быстро устаревают |
| `har` | 3 дня | Сетевая диагностика, очень большие файлы |

## Механизм очистки

- Для локальной разработки используется скрипт `src/cleanup_minio.py`.
- Для production рекомендуется настроить ILM (Information Lifecycle Management) непосредственно в MinIO.

## Связанные файлы

- `src/artifact_saver.py` — загрузка артефактов в MinIO.
- `src/cleanup_minio.py` — ручная очистка старых объектов.
